# surveyreports

Automate reporting analyses over multiple variables for Taylor series,
replicate weight, and two-phase survey designs.

## Installation

``` r

# From GitHub (development version)
pak::pak("JDenn0514/surveyreports")

# From r-universe (pre-built binaries, no GitHub PAT needed)
install.packages("surveyreports", repos = "https://jdenn0514.r-universe.dev")
```

## Usage

``` r

library(surveyreports)
```

For full documentation, see the [pkgdown
site](https://jdenn0514.github.io/surveyreports/).
