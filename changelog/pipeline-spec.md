# chore(pipeline): port the pipeline-spec and pipeline-implement workflows from surveywts

**Date**: 2026-09-09
**Branch**: JDenn0514/pipeline-spec

## Changes

- Add the `pipeline-spec` skill — drives a request from NEW to SPEC_READY with a
  state machine, Deep Comprehension Stage 0, and a capped review loop
- Add the `pipeline-implement` skill — drives SPEC_READY to PLAN_READY and
  produces `impl-{id}.md`, a PR map whose acceptance criteria carry both the
  spec contract items and the test-spec scenarios
- Add the `pipeline-shared` reference library — state model, artifact schemas,
  pipeline isolation, signals, workspace layout, and the R package profile
- Add six pipeline agents — planner, extractor, builder, tester, reviewer, and
  shipper
- Add `.claude/standards/function-documentation.md` — the documentation tier
  system used by the planner, the builder, and the reviewer
- Add the gate scripts `run-gates.sh` and `covr-report.R`
- Extend `spec-workflow` Stage 1 to produce two independently-sufficient
  artifacts: `spec-{id}.md` for the builder and `test-spec-{id}.md` for the
  tester
- Standardize roxygen2 on `@returns` instead of `@return` across all exported
  functions
- Align DESCRIPTION and the generated `man/` files with roxygen2 8.1.0
- Gitignore `.surveyreports-workspace/`, the per-request runtime directory
